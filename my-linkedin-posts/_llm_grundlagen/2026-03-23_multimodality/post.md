# March 23, 2026

In den letzten zwei Jahren habe ich mehr als 200 Leute zum Thema AI und Prompt Engineering geschult. Jedes Mal kommt dieselbe Frage:
"Warum funktioniert das nicht so, wie ich mir das vorgestellt habe?"

Meine Antwort fängt immer gleich an: Der Chatbot sieht deine Dateien nicht so wie du. Denn hinter dem Chatbot steckt ein SPRACHmodell.

Im letzten Post habe ich erklärt, dass ein LLM als Input eine Reihe an Tokens bekommt. Diese Tokens sind erstmal einfach Text.

Wenn du dir als Mensch eine PDF anschaust, kannst du den Text lesen, du siehst das Layout, du siehst die eingebetteten Bilder.

Ein LLM sieht davon nichts. Eine PDF ist kein Text. Sie ist eine binäre Datei, und ein LLM kann damit schlicht nichts anfangen.

Wenn du eine PDF bei ChatGPT hochlädst, liest das Modell die Datei nicht. Der Chatbot nutzt vorher ein Skript, das den Text rauszieht. Dabei geht Struktur verloren. Manchmal viel.

Aus einer sauberen Excel-Tabelle wird so ein Fließtext, in dem der Umsatz von 2025 plötzlich an der Jahreszahl von 2024 klebt. Das LLM sieht nur noch Buchstabensalat und fängt an zu raten.

Stell dir vor, jemand liest dir eine verschachtelte Excel-Tabelle Zeile für Zeile laut am Telefon vor. Genauso fühlt sich das für das Sprachmodell an. Dass es da den Faden verliert, ist eigentlich logisch.

Ich sage euch: Wer verstanden hat, wie Chatbots mit verschiedenen Dateiformaten umgehen, der kann diese Tools auch richtig nutzen. Und muss sich weniger oft fragen: "Warum funktioniert das nicht so, wie ich mir das vorgestellt habe?"

Wie multimodale Modelle das Problem lösen, zeige ich im nächsten Post.
